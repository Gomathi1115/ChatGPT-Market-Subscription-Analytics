# ChatGPT Market & Subscription Analytics

### India vs USA | Data Analytics Portfolio Project

An end-to-end data analytics project exploring simulated subscription transactions across India and the USA, alongside separately sourced public ChatGPT usage trends.

**Tools Used:** Python, Pandas, PostgreSQL, SQL, Power BI, Excel

### Project Highlights
- Analysed 50,000 simulated transactions
- Performed data cleaning and validation using Python
- Used SQL for business analysis
- Developed a four-page Power BI dashboard
- Explored revenue, payment status, customer segments, subscription plans and public usage trends
